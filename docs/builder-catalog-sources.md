# Configuration builder catalog sources

The builder's settings catalog (`public/builder/catalog.json`) cites these pages. Each line gives the date the page was read.
Re-check a tool's pages when it ships a new admin or managed-settings release, update the matching catalog entries and their `researched` dates, and run `go test ./internal/builder`.
