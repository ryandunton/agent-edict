Build a policy

Drag settings into your file, or use Add. Hover over a setting's ? to see what it does for each agent on each OS. Copy the YAML into your policy repository when you're done.

The builder can't run from a file on disk

Browsers block this page's scripts when it's opened straight from disk (a file:// address), so the settings library stays empty. Open it through a web server instead. From the repository:

make builder
python3 -m http.server --directory public 8000

Then go to http://localhost:8000/builder/, or use the published copy at agent-edict.com/builder.

Some of the builder's files are missing

This site is missing scripts the builder needs, so the settings library can't start. Publish the whole public/ folder with its subfolders, including builder/js/, and run make builder first: it creates builder/edict.wasm, edict.wasm.gz and wasm_exec.js. Uploading files one by one often skips some, so deploy from a build instead.

The published copy is at agent-edict.com/builder.
